## 🌸 Tentang Proyek

**Wisata Keliling Dunia** adalah website promosi pariwisata yang dirancang untuk memperkenalkan daya tarik wisata bertema berbagai negara di dunia yang berada di Majalengka, Jawa Barat.

Website ini membantu pengunjung mengenal berbagai spot wisata, melihat koleksi foto, mengetahui informasi harga tiket, menikmati video perjalanan, dan menemukan lokasi wisata melalui Google Maps.

Dengan desain modern bernuansa **sage green** dan **pink peach**, website ini menghadirkan tampilan yang menarik, nyaman dilihat, dan responsif di berbagai ukuran layar.

> 🌿 *Satu tempat, berbagai suasana dunia, dan banyak kenangan untuk diciptakan.*

## 🎯 Tujuan Website

- Memperkenalkan destinasi dan daya tarik wisata kepada masyarakat.
- Menyediakan informasi wisata dalam satu halaman yang mudah diakses.
- Menampilkan dokumentasi foto dan video pengalaman berwisata.
- Membantu pengunjung mengetahui harga tiket dan fasilitas tambahan.
- Memudahkan pengunjung menemukan lokasi wisata.

## 🚀 Cara Menjalankan Website

1. Siapkan folder proyek beserta file HTML, CSS, dan JavaScript.
2. Masukkan seluruh foto ke folder `images/`.
3. Masukkan video berformat MP4 ke folder `videos/`.
4. Pastikan lokasi dan nama setiap file sesuai dengan kode.
5. Buka file `index.html` menggunakan browser, seperti Google Chrome.
6. Jelajahi bagian Beranda, Destinasi, Galeri, Paket & Harga, Vlog, Informasi, dan Lokasi.
